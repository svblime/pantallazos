# SVBLIME · Sitio completo (versión 14)

`public_html/` es **todo el sitio svblime.cl** listo para subir:

- La web nueva en la raíz (sin contraseña, visible para Google): portada, servicios, preguntas frecuentes y contacto.
- `mejorada/`: la versión mejorada, **con clave `svblime`** y oculta para Google → svblime.cl/mejorada/
- Las propuestas `propuesta`, `propuestasuv` y `backtojungle`, con sus claves de siempre.

## Subirlo

1. Botón verde **Code** → **Download ZIP** y descomprimir.
2. En FileZilla, borrar el contenido de `public_html` del servidor **menos el `.htaccess`** (si existe).
3. Subir **todo lo que hay dentro** de la carpeta `public_html` del ZIP.
4. Abrir https://svblime.cl y recargar con Ctrl+Shift+R (Mac: Cmd+Shift+R).
